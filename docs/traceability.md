# M4 traceability — P9 evidence

Owner: Wenura Kavinda (M4). Verified 2026-10-09. Source references follow the reviewed G39 mapping already recorded in the [M4 plan](./M4_Analytics_and_Export_Plan.md#appendix-a--flow-traceability); original source PDFs are not reinterpreted here.

The [improved scenario and sequence](./M4_Analytics_and_Export_Plan.md#75-improved-sequence-diagram-corrected-numbering-critique-c12) and the plan's §2.2/§7/§8/§9 describe implementation decisions. One immutable audited run supplies UI and exports; C9 makes downloading optional. A11 replaces raw patrol breadcrumbs with aggregated cell coverage for §8.5 privacy. Source series are separate events, not deduplicated real-world conflicts. Per-park settings and sample sizes replace unsupported confidence scores. Researchers have one assigned park and own-run history; managers have own-park history.

API prefix is `/api`: E1 `GET /analytics/options`; E2 `POST /reports/runs`; E3 `GET /reports/runs/:runId`; E4 `POST /reports/runs/:runId/exports`; E5 `GET /reports/runs`. UI routes: `/analytics`, `/analytics/map`, `/analytics/patrol-gaps`, `/analytics/conflicts`, `/reports`.

Tests below are relative to `apps/api/src/modules/analytics` unless named Ops (`apps/ops/src/features/analytics/pages`), shared or `app/App.test.tsx` (`apps/ops/src`). All listed tests passed. [Coverage and commands](./evidence/m4/checks.md), [browser/export manifest](./evidence/m4/browser-and-export-checks.json), and [screenshots/exports](./evidence/m4/README.md) provide the supporting evidence.
